# Como Sincronizar o Booking.com com o RentlyHub

Siga estes passos para importar suas reservas do Booking.com para o RentlyHub:

## 1. Localizar o link iCal no Booking.com
1. Acesse o [Booking.com Extranet](https://admin.booking.com/).
2. Clique na aba **Calendário e Preços** (ou **Tarifas e Disponibilidade**).
3. Selecione a opção **Sincronizar Calendários**.
4. Clique em **Adicionar Conexão de Calendário**.
5. No passo 1 (Importar), você pode pular clicando em "Próximo passo" se quiser apenas exportar o calendário do Booking para o RentlyHub.
6. No passo 2 (Exportar), o Booking fornecerá um link que termina em `.ics`.
7. **Copie esse link**.

## 2. Configurar no RentlyHub
1. No RentlyHub, abra o modal de seu imóvel.
2. No campo **Sincronizar de Outra Plataforma**, cole o link que você copiou.
3. Clique em **Salvar** e use o botão **Sincronizar** para carregar as reservas imediatamente.

> [!TIP]
> O Booking.com pode demorar alguns minutos para atualizar o status das reservas no link iCal após uma nova venda.
